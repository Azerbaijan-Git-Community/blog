# Azerbaijan GitHub Community Blog

> [!IMPORTANT]
> This repository is archived and no longer accepts posts. The community blog has moved to [Omicron](https://omicron.blog).

Community members now write on Omicron, and their posts appear on the [community blog](https://githubcommunity.az/blog). There are no more MDX files or pull requests.

## How to publish

1. Create an account on [Omicron](https://omicron.blog).
2. Sign in to the [community website](https://githubcommunity.az/blog) with GitHub.
3. Click **Connect Omicron** and approve the connection.
4. Choose which of your existing posts to show.

New posts on Omicron then appear on the community blog automatically. You can hide any post from **My blog posts** in the avatar menu.
